A standalone, single-process GitHub-compatible git forge: git smart HTTP (upload-pack v2 and receive-pack v0), REST v3, GraphQL v4 and MCP, all backed by an in-memory git object store with no external services and no git binary.

## Run it

```sh
node --experimental-strip-types main.ts
```
